# Brand assets

Loads when working under `src/frontend/src/lib/assets/`. The frontend-wide rules are in `src/frontend/CLAUDE.md` and the root `CLAUDE.md`'s "Frontend hard rules".

## Brand assets

The product mark is the **single asset** `src/frontend/src/lib/assets/logo.svg` (phase-17, task-130; crystal-ball concept adopted later from `planning/inputdata/LogoSuggestion.png`): a rounded-square chip filled with the `--gradient-brand` green carrying a white **forecasting crystal ball** on a tiered pedestal — a translucent glass sphere (bright rim + top-left shine) holding three rising bars and a dotted lead-in that becomes a solid trend arrow taking off up-right (the dots echo the earlier three-point/PERT motif). The bars are faint, the arrow and rim are chunky, and fine detail is kept minimal because it dissolves in the 16 px favicon. Components import it (`import logo from '$lib/assets/logo.svg'`); it is the header lockup mark and the dev-login dialog mark, and it drives `<link rel="icon" type="image/svg+xml">` (the session-room chrome that carried a third copy was deleted by task-141). **The wordmark is deliberately NOT baked into the SVG** — text inside an `<img>`-referenced SVG cannot use the Google-hosted Poppins webfont, so the lockup is `mark <img>` + HTML text styled with `font-heading`. Beside that wordmark the mark is decorative (`alt="" aria-hidden="true"`) so a screen reader does not announce the name twice; standalone uses (the dev-login dialog) carry a real `alt`. The raster app icons and manifest in `src/frontend/static/` (`icon-{16,32,48,180,192,512}.png`, `favicon-32.png`, `favicon.ico`, `apple-touch-icon.png`, `apple-touch-icon-precomposed.png`, `site.webmanifest`) are **generated** from the SVG by `npm run gen:icons` (`src/frontend/scripts/generate-icons.mjs`, which rasterises via Playwright's bundled Chromium — do NOT add `sharp` or any other image dependency) and committed, so a plain `npm run build` never needs a browser. Re-run `gen:icons` whenever `logo.svg` changes. The README screenshots in `docs/images/` follow the same pattern via `npm run gen:screenshots` (`scripts/capture-screenshots.mjs`, task-153) — same bundled-Chromium rule, no image dependency — but they additionally need a RUNNING dev stack and exit non-zero without one; re-run them when the screens they show change materially. That script switches the capture user's UI **language** to English and restores what it found when it finishes, failure paths included (task-180). Keep that `finally` as hygiene for a human's dev stack, but it is no longer load-bearing for the Playwright suite: `e2e/global-setup.ts` re-pins the shared dev users to `E2E_LANG` before every run (task-190). `favicon.ico` is packed by the script itself (an ICO container wrapping the 16/32/48 PNGs — no encoder dependency), and `favicon.ico` / `apple-touch-icon-precomposed.png` exist because browsers and iOS probe those well-known paths on their own regardless of the `<link>` tags. Brand strings live under the `brand.*` i18n keys (`brand.name`, `brand.logoAlt`) like every other UI string. The legacy third-party corporate mark that predated it was removed by task-130 and must not be reintroduced.
